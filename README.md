# Puerto Viejo Volleyball Academy

Static Astro website draft for PVVA.

## Run locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

The site is generated as static HTML. Page routes live in `src/pages/`, shared layout and navigation in `src/layouts/` and `src/components/`, and the editable program list in `src/data/programs.ts`.

## Before launch

- Replace the temporary Unsplash photos with approved PVVA images and use the supplied logo asset.
- Confirm the Instagram profile URL, exact court location/map pin, and regular training schedule.
- Confirm program age ranges, fees, coach biographies, upcoming camps, tournaments, and registration details.
- Review privacy wording and choose a secure registration process before collecting athlete or guardian information.
- Configure HTTPS and redirect the non-`www` domain to `https://www.pvvolleyballacademy.com/` with the selected hosting provider.
- Have a fluent Spanish-speaking PVVA representative review the draft translations and metadata.
